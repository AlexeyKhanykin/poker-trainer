# Покерный тренер

Офлайн-тренажёр покера для новичка: открывается двойным щелчком по `poker-trainer.html`, без сервера и интернета. Два языка: русский (основной, по умолчанию) и английский — переключатель RU/EN в шапке. Та же папка публикуется как сайт на GitHub Pages и ставится на телефон как приложение (PWA), работает и без сети.

## Устройство

Файлы в этой папке — и есть исходники (сборки нет, ничего не генерируется):

- `poker-trainer.html` — разметка и порядок подключения скриптов.
- `js/i18n.js` (`PKI18n`) — язык: перевод текстов, формы числа, числа, перевод статичной разметки; выбор хранится в localStorage (`pk-lang`).
- `js/i18n-en.js` — английский словарь: ключ — русский текст, значение — перевод.
- `css/style.css` — все стили (светлая и тёмная тема, мобильная вёрстка).
- `js/core.js` (`PK`) — карты, оценка рук, варианты покера, банки, правила стола, боты, советы префлопа.
- `js/drills.js` (`PKDrills`) — задания «Шансы», «Играть или сбросить», «Ситуации» (фолд/колл/рейз после флопа), «Мои ошибки», объяснения, пояса.
- `js/stats.js` (`PKStats`) — анализ статистики (чистые функции).
- `js/store.js` (`PKStore`) — хранение: IndexedDB → localStorage → память; настройки в localStorage.
- `js/sound.js` (`PKSound`) — звуки, синтезированные WebAudio.
- `js/ui.js` — весь интерфейс.
- `index.html` — корень сайта, перенаправляет на `poker-trainer.html`.
- `manifest.webmanifest`, `icons/` — установка как приложение; PNG-иконки рисует `node tools/make-icons.js` из `icons/icon.svg`.
- `sw.js` — офлайн-работа сайта: сначала сеть, без сети — сохранённые файлы. Регистрируется только по http(s), при открытии файла двойным щелчком не нужен.
- `.nojekyll` — GitHub Pages отдаёт файлы как есть.

## Тесты — обязательно

После каждого значимого изменения кода (логика, интерфейс, стили, тексты) запускать тесты и не считать работу законченной, пока они не зелёные:

```bash
node tests/run.js           # всё: логика + интерфейс в Chrome без окна (~15 мин)
node tests/run.js --quick   # быстрый прогон: меньше случайных повторов, каждое третье устройство
node tests/run.js --unit    # только логика, без браузера
node tests/run.js bots odds # только наборы с этими словами в имени файла
```

- Нужны Node 22+ и установленный Chrome (путь можно задать в `CHROME_PATH`); внешних зависимостей нет.
- `tests/unit/*.test.js` — логика; `tests/ui/*.test.js` — сценарии в настоящем Chrome; скриншоты кладутся в `tests/out/`.
- `tests/ui/mobile.test.js` — вёрстка на телефоне (320–412 px), планшете, в горизонтальной ориентации и на компьютере: нет прокрутки вбок, кнопки нажимаются касанием, за столом ничего не налезает (в том числе «самый тесный» стол через `window.__pkui`). Только некоторые экраны: `SIZES=360,390 node tests/ui/mobile.test.js`.
- `tests/ui/devices.test.js` — 34 популярных устройства (iPhone от SE до 16 Pro Max, Galaxy, Pixel, Z Fold, iPad, телефоны лёжа, ноутбуки и мониторы до 2560 px): вкладки, режимы тренажёра, «самый тесный» стол, окно настроек, кнопки хода; второй проход на каждом — светлая тема и английский. Новое устройство — строка в `DEVICES`; только некоторые: `DEVICES=iPad,1366 node tests/ui/devices.test.js`. Общие замеры стола — `tests/lib/layout.js`.
- «Самый тесный» стол — у всех ставка 10 000 и подпись «рейз до 10 000», кнопка дилера по очереди у каждого места. Ставки и подписи реальны (стек до 5000), так что падение этой проверки — ошибка вёрстки, а не теста.
- `node tests/lib/shots.js 390x844 768x1024` — скриншоты всех вкладок в `tests/out/shots/` для ручного просмотра; `PK_LANG=en` — то же по-английски.
- `tests/unit/i18n.test.js` — у каждого текста из кода есть перевод, логика на английском не выдаёт русских букв; `tests/ui/i18n.test.js` — английская версия в Chrome: все вкладки, режимы, окна, телефон.
- `tests/unit/drills-spot.test.js` — «Ситуации»: ответ сверяется с независимым пересчётом шанса на эталонном оценщике.
- `tests/unit/pwa.test.js` и `tests/ui/pwa.test.js` — манифест, иконки, список офлайн-файлов; сайт с локального сервера ставится как приложение и работает после настоящей остановки сервера.
- `tests/ui/long.test.js` — 1000 раздач подряд (память, элементы страницы, скорость) и история почти до лимитов (≈10 000 раздач, 50 000 ответов) с перезагрузкой.
- `tests/ui/visual.test.js` — скриншоты 5 экранов × (компьютер, телефон) × (тёмная, светлая, английский) сравниваются с эталонами в `tests/visual/` до пикселя (допуск 0,05 %). Случайность и дата заморожены, так что снимки повторяются точь-в-точь. Внешний вид изменён намеренно — посмотреть `tests/out/visual/*-diff.png` и обновить: `UPDATE_SNAPSHOTS=1 node tests/ui/visual.test.js`. Эталоны зависят от шрифтов системы: на другом компьютере их пересоздать.
- Интерфейсные наборы запускаются строго по одному (два Chrome сразу тормозят друг друга).
- `tests/lib/harness.js` — загрузка модулей и проверки (`TS.check`, `TS.eq`, …); `tests/lib/ref-eval.js` — независимый эталонный оценщик рук; `tests/lib/cdp.js` — мини-драйвер Chrome.
- Новая функция или исправленная ошибка — добавить проверку на неё. Если тест упал, сначала понять, ошибка в коде или в ожидании теста, и сказать об этом честно.

## Правила кода

- Тексты для пользователя пишутся по-русски и всегда через перевод: `T('Сыграно {n}.', { n })` в core/drills/stats/store, `tr(…)` в ui.js (там `T` занято состоянием тренажёра). Склейку из кусков не делать — одна фраза с `{переменными}`, иначе по-английски порядок слов ломается.
- Новый текст — сразу добавить перевод в `js/i18n-en.js` (значение — строка с теми же `{переменными}` или функция). Статичный текст в HTML переводится сам, но его ключ тоже нужен в словаре.
- Склонение числительных: `plural(n, 'карта', 'карты', 'карт')` / `ru(…)`; для английского в словаре пара `'карта': ['card', 'cards']`.
- Не сравнивать с русским текстом в логике (имена ботов, подписи действий): для типа действия есть `p.lastKind`.
- Даты и дни считать по календарю (`setDate`), а не шагами по 24 часа — иначе ломается переход на летнее время.
- Сила стартовой руки не должна зависеть от мастей (K♥J♥ и K♠J♠ — одна рука).
- Новый файл, который нужен странице (скрипт, стиль, иконка), — добавить в `ASSETS` в `sw.js`, иначе без сети он не загрузится (`tests/unit/pwa.test.js` это ловит). Номер в `CACHE` менять, когда файл удалён или переименован.
- Раскладка стола: `SEAT_POS` (компьютер/планшет) и `SEAT_POS_PHONE` (телефон, ≤720 px) в `js/ui.js`. После их правки — `mobile.test.js`.
