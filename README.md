# Покерный тренер

Тренажёр покера для новичка: учит названиям комбинаций, шансам и аутам, решениям до и после флопа, а за столом — игре против ботов с подсказками и разбором каждой раздачи. Холдем, Омаха, Омаха-5 и шорт-дек. Русский и английский.

## Как открыть

- **На компьютере** — двойной щелчок по `index.html`. Ни сервер, ни интернет не нужны.
- **На сайте** — откройте адрес сайта на GitHub Pages (`https://<пользователь>.github.io/<репозиторий>/`).
- **Как приложение на телефоне.** На Android в Chrome: «Статистика → Данные → Установить приложение» или меню ⋮ → «Установить приложение». На iPhone в Safari: «Поделиться → На экран „Домой“». После первого открытия приложение работает и без сети.

Статистика хранится в браузере отдельно для каждого способа открытия: в файле, на сайте и в установленном приложении она своя. Чтобы перенести её, нажмите «Статистика → Данные → Скачать резервную копию», а в новом месте — «Загрузить из файла…».

## Публикация на GitHub Pages

Сборки нет: сайт — это сама папка. В настройках репозитория, в разделе Pages, выберите источник «Deploy from a branch», ветку `main` и папку `/ (root)`. Тренажёр открывается прямо по адресу сайта.

## Тесты

Нужны Node 22+ и Chrome; внешних зависимостей нет.

```bash
node tests/run.js           # всё (логика + интерфейс в Chrome без окна)
node tests/run.js --quick   # быстрый прогон
node tests/run.js --unit    # только логика
```

Тесты проверяют оценку рук по независимому эталону, банки и сайд-поты, ботов, задания тренажёра и английский перевод. Интерфейс прогоняется на 34 популярных устройствах в обеих темах, с проверкой офлайн-режима и долгой сессии. Скриншоты сравниваются с эталонами в `tests/visual/`. Подробнее — в `CLAUDE.md`.
